Semantic and Non Semantic Tags in HTML

Semantic and Non Semantic tags in HTML are used to show the content in different ways. Semantic tags or elements refers to an element which provides meanings of the content to the browser as well as Developer. It helps to improve SEO of the webpages or websites.

Non Semantic tags are tags which does not provide any meaning to the browser or developer. In HTML we have multiple non Semantic tags such as div, span etc.
